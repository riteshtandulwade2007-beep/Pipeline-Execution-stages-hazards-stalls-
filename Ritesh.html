What is Pipeline Execution?

Pipelining allows the CPU to process different instructions in overlapping stages. This improves instruction throughput.

1. Fetch (IF)

Get the instruction from memory.

2. Decode (ID)

Understand the instruction.

3. Execute (EX)

Perform the operation.

4. Memory (MEM)

Access data memory if required.

5. Write Back (WB)

Save the result in a register.
